# ArtWall TV — Data

Static content index for the ArtWall TV app. Served free via GitHub raw CDN.

- `master-index.json` — curated public-domain artworks (CC0 / Public Domain)
- `music-index.json` — public-domain classical tracks (CC0 / Public Domain)

Regenerate with the app's `pipeline/` scripts and push here to update every
installed app on next launch — no store release needed.
